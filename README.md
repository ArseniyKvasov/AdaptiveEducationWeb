# Adaptive Learning App (Web Interface)

Это основное веб-приложение для платформы адаптивного обучения. Оно отвечает за интерфейс преподавателя (загрузка видео, анализ) и интерфейс студента (изучение конспекта, прохождение тестов).

## Быстрый запуск (Production)

Самый простой способ развернуть приложение — использовать Docker Compose из корня проекта.

### 1. Подготовка окружения
Создайте файл `.env` в директории `Web/` на основе `.env.example`:

```env
PORT=8000
DB_PATH=./data/app.db
SESSION_SECRET=your-very-secure-secret-here

# Связь с ML-сервисом
ML_URL=http://ml-service:8000
ML_API_KEY=your-shared-api-key-here

# Лимиты
MAX_CONCURRENT_GENERATIONS=3
MAX_QUEUE_SIZE=10
```

### 2. Запуск через Docker
Находясь в корне проекта, выполните:

```bash
docker compose up -d --build
```

Приложение будет доступно по адресу: `http://localhost:8090` (или другой порт, если он изменен в `docker-compose.yml`).

## Минимальные настройки .env

Для работы в продакшене обязательно настройте:
- `SESSION_SECRET`: любая длинная случайная строка для защиты сессий.
- `ML_URL`: адрес, по которому доступен ваш запущенный ML-сервис.
- `ML_API_KEY`: ключ, который совпадает с `API_KEY` в настройках ML-сервиса.

## Функционал
- **Загрузка материалов**: Обработка видео и аудио уроков.
- **Адаптивный конспект**: Генерация структурированного материала с поддержкой LaTeX.
- **Умные тесты**: Автоматическое создание вопросов и проверка открытых ответов через ИИ.
- **Аналитика для учителя**: Детальный разбор речи, структуры урока и вовлеченности студентов.
- **Авто-сохранение**: История генераций хранится локально в SQLite.

## Архитектура
Приложение разделяет тяжелые задачи на подшаги:
1. Нарезка аудио на чанки (FFmpeg).
2. Параллельная транскрибация через ML-сервис.
3. Посекционная агрегация аналитики (Sectoral Aggregation) для поддержки длинных записей.
4. Сборка итогового конспекта методом Map-Reduce.
